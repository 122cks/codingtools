[선생님 필독] 우리 키트 보드 규격: "Pico WH" vs 최신 "Pico 2W" 구분 안내

보드 인식 실패 방지 1순위 ▶ 1회차 00:09:21 보드 선택 시연

선생님, 본 키트에 포함된 제어 보드는 라즈베리 파이 Pico WH (RP2040 칩셋)입니다. 최근 시중에 출시된 신형 모델인 Pico 2 및 Pico 2W (RP2350 칩셋)와는 하드웨어 코어와 펌웨어 파일이 완전히 다른 버전입니다. 버전을 잘못 알고 최신 'Pico 2W' 펌웨어를 다운받아 주입하면 보드 연결부터 아예 불가능해지는 현상이 발생하므로 아래 내용을 반드시 확인해 주시기 바랍니다.

✅ 씨마스 키트 기본 보드: Raspberry Pi Pico WH ▶ 2회차 00:09:43
  • 핵심 코어: RP2040 듀얼코어 (ARM Cortex-M0+ 기반, 안정성 검증 표준)
  • 명칭 속 의미: W (Wi-Fi/Bluetooth 무선 모듈) + H (공장 출하 시 헤더핀 납땜 완료)
  • 수업 장점: 학교에서 교사나 학생이 인두기로 40핀을 납땜할 필요가 전혀 없으며, 개봉 즉시 확장 쉴드에 결합 가능 (2회차 00:10:10)
  • 설치 펌웨어: MicroPython 사이트에서 반드시 숫자 2가 없는 rp2-pico-w-*.uf2 파일을 다운로드하여 주입 (1회차 00:09:21)
🚫 다운로드 혼동 금지: Raspberry Pi Pico 2 / Pico 2W ▶ 1회차 01:04:29
  • 핵심 코어: RP2350 (신형 RISC-V/Cortex-M33 아키텍처)
  • 자주 발생하는 실수: 인터넷 검색 시 '최신 버전이 좋겠지'라는 생각으로 Pico 2 또는 Pico 2W용 펌웨어(.uf2)를 다운받아 피코에 넣는 경우
  • 발생 증상: 보드 먹통(벽돌화), Thonny IDE에서 COM 포트 미인식, 첫 수업부터 보드 연결 자체가 불가능해짐 (1회차 01:04:29)
  • 교사 예방 지도: 학생들에게 펌웨어 다운로드 시 목록에서 숫자 2가 붙은 보드가 아닌 'Raspberry Pi Pico W'를 명확히 선택하도록 지도해 주십시오.
💡
선생님을 위한 1분 긴급 복구 팁: 만약 학생이 실수로 잘못된 펌웨어를 넣어 보드가 인식되지 않는다면, USB를 뽑은 후 보드의 하얀색 BOOTSEL(부트셋) 버튼을 꾹 누른 상태로 USB를 다시 꽂으십시오 (1회차 00:10:19). 열리는 RPI-RP2 드라이브에 라즈베리 파이 공식 메모리 초기화 파일인 flash_nuke.uf2를 넣어 초기화한 뒤, 올바른 Pico W 펌웨어를 넣으면 100% 정상 복구됩니다.

Pico WH 보드 & 전용 확장 쉴드

듀얼 코어 RP2040, 2.4GHz 무선 캔 내장. 공장 납땜 헤더핀(H) 기본 장착. 전용 확장 쉴드 상단에 핀 번호가 각인되어 배선 오류를 방지하며 상시 접지(GND) 8개와 전원 분리를 제공합니다.

• 부팅 진입: BOOTSEL 버튼 누른 채 USB 연결
• 결합 보관: 쉴드에서 보드를 분리하지 말고 결합 상태로 보관 (2회차 00:10:10)
입력 센서 ▶ 1회차 00:27:18

온습도 센서 모듈 (DHT11)

교재 원안의 심박 센서 대신 입김을 '후-' 불면 즉시 습도가 40%에서 70~80%로 치솟는 DHT11을 채택하여 교실 실습 성공률 100%를 보장합니다 (1회차 00:37:47).

• 신호선 (Data/S): GP 22번 (00:29:23)
• 전원선 (VCC/+): 3.3V 핀 (확장보드 빨간 핀)
• 접지선 (GND/-): GND 핀 (확장보드 검정 핀)
출력 액추에이터 ▶ 1회차 00:44:02

네오픽셀 RGB LED (WS2812B 4구)

신호선 1개로 4구 LED의 RGB(0~255) 색상을 개별 제어합니다. 온습도 상태 경보등 및 실내 환경 알리미 시스템을 직관적으로 시각화합니다.

• 신호선 (DIN): GP 16번 (00:44:02)
• 전원선 (5V): 5V (확장보드 붉은 USB 핀)
• 접지선 (GND): GND 핀 (확장보드 검정 핀)
⚠️
배선 필수 주의 (교사 지도 포인트): 네오픽셀 LED 4구 바는 LED가 여러 개 켜질 때 전류 소모량이 큽니다. 피코 보드의 일반 3.3V 핀에 연결하면 전압 강하로 보드가 리셋되거나 오작동할 수 있으므로, 반드시 확장 쉴드 하단의 붉은색 5V(USB 전원) 핀에 연결하도록 지도해 주십시오 (1회차 00:44:02 설명 검증).

피지컬 컴퓨팅 단계별 수업 지도안 (표준 6차시 모델)

기초 하드웨어 설정부터 독립 자율 구동 프로젝트 완성까지 교과 최적화 시퀀스 (영상 분·초 매핑)

권장 IDE: Thonny Python (MicroPython)
🎯 학습 목표 Pico WH에 MicroPython 최신 펌웨어(`rp2-pico-w-*.uf2`)를 주입하고, Thonny 인터프리터 설정 및 온보드 LED 깜빡임 구현
🛠️ 준비 교구 Pico WH 보드, USB 데이터 케이블, PC (Thonny IDE 설치)
💡 교사 지도 팁 반드시 'Pico W' 펌웨어를 선택하게 하고, 내장 LED는 Pin("LED", Pin.OUT)으로 선언해야 동작합니다 (1회차 00:26:29).
# 1차시: Pico WH 온보드 LED 제어 기본 코드 from machine import Pin import time led = Pin("LED", Pin.OUT) # Pico WH 전용 무선 실드캔 상단 LED 선언 while True: led.on() # LED 켜기 (3.3V 출력) time.sleep(1) # 1초 대기 led.off() # LED 끄기 time.sleep(1) # 1초 대기
🎯 학습 목표 확장 쉴드에 DHT11(GP22)을 결선하고, 1초 주기로 온·습도 값을 읽어와 조건문(if-else)으로 LED 반응 제어
🛠️ 준비 교구 Pico WH, 전용 확장 쉴드, DHT11 온습도 모듈, 점퍼선 3가닥
💡 교사 지도 팁 센서에 '후-' 하고 입김을 불면 습도가 즉시 60~80%로 치솟아 학생들의 흥미와 집중도가 극대화됩니다 (1회차 00:37:47).
# 2차시: GP22 온습도 측정 및 습도 임계값 조건 제어 from machine import Pin import time import dht sensor = dht.DHT11(Pin(22)) # GP 22번 핀에 연결 led = Pin("LED", Pin.OUT) while True: time.sleep(1) # 센서 샘플링 최소 간격 (1초) sensor.measure() temp = sensor.temperature() humi = sensor.humidity() print(f"온도: {temp}°C | 습도: {humi}%") if humi >= 50: # 입김을 불어 습도 50% 이상 시 점등 led.on() else: led.off()
🎯 학습 목표 RGB 빛의 3원색(0~255) 원리 이해, 네오픽셀 전체 점등(`fill`) 및 개별 인덱스(`np[i]`) 순차 점등 반복문 구현
🛠️ 준비 교구 네오픽셀 4구 바, 점퍼선 (GP16 신호선, 5V 전원, GND 접지)
💡 교사 지도 팁 배열 인덱스는 0번부터 시작함(0, 1, 2, 3)을 강조하고, 색상 값 대입 후 반드시 np.write()를 실행해야 실제 점등됩니다.
# 3차시: 네오픽셀 4구 순차 점등 제어 (GP16 신호선, 확장쉴드 5V 전원) from machine import Pin import neopixel import time np = neopixel.NeoPixel(Pin(16), 4) # GP16번 핀, 4구 LED while True: # 0번부터 3번까지 차례로 빨간색 순차 점등 for i in range(4): np[i] = (255, 0, 0) np.write() time.sleep(0.3) time.sleep(0.5) # 전체 소등 np.fill((0, 0, 0)) np.write() time.sleep(0.5)
🎯 학습 목표 센서 입력값(온도·습도)의 다중 조건문(elif)에 따라 네오픽셀 LED 색상(적/녹/청)을 상태 표시 신호등으로 연동 제어
🛠️ 준비 교구 Pico WH, 확장 쉴드, DHT11(GP22), 네오픽셀 4구(GP16)
💡 교사 지도 팁 '적정 습도(40~60%)는 녹색, 건조(40% 미만)는 파란색, 다습(60% 초과)은 빨간색' 등 실생활 환경 기준값을 스스로 설계하게 지도합니다.
🎯 학습 목표 Pico WH의 내장 무선 칩셋(CYW43439) BLE 기능을 활성화하여 스마트폰 또는 크롬 웹 브라우저로 실시간 센서 데이터 수신
🛠️ 준비 교구 Pico WH 키트, Web Bluetooth 지원 기기 (스마트폰 또는 크롬 브라우저 PC)
💡 교사 지도 팁 학교 스쿨넷망에서 Wi-Fi 접속이 제한되더라도, BLE 통신은 외부 인터넷망 연결 없이 기기 간 1:1로 100% 정상 작동합니다 (2회차 01:52:49 성원경 교사 검증).
🎯 학습 목표 완성 코드를 피코 보드 내부 저장소의 `main.py`로 영구 저장하고, PC 연결 없이 보조배터리로 독립 자율 구동 산출물 완성 및 상호 동료 평가
🛠️ 준비 교구 완성된 실습 회로, 보조배터리(또는 USB 5V 어댑터), 상호 평가지

# [씨마스 피코 WH 표준 실습] 온습도 센서(GP22) + 네오픽셀 4구(GP16) 스마트 환경 알리미
# 하드웨어: Raspberry Pi Pico WH (RP2040) + 전용 확장 쉴드
# 파일명: main.py (피코 보드 내부 저장소에 저장 시 보조배터리로 자동 무한 루프 구동)

from machine import Pin
import neopixel
import time
import dht

# 1. 핀 및 센서/액추에이터 객체 선언 (확장 쉴드 표준 매핑)
dht_sensor = dht.DHT11(Pin(22))         # GP 22번: DHT11 온습도 데이터선
board_led = Pin("LED", Pin.OUT)         # Pico WH 온보드 무선 캔 상단 LED
pixels = neopixel.NeoPixel(Pin(16), 4)  # GP 16번: 네오픽셀 4구 (확장 쉴드 붉은색 5V 전원 연결)

print("=== 피코 WH 스마트 환경 알리미 시스템 가동 ===")

while True:
    try:
        time.sleep(1)  # DHT11 센서 최소 샘플링 간격 유지
        dht_sensor.measure()
        temperature = dht_sensor.temperature()
        humidity = dht_sensor.humidity()
        
        print(f"[측정 결과] 현재 온도: {temperature}°C | 현재 습도: {humidity}%")
        
        # 2. 다중 조건 판단 및 피지컬 피드백 제어
        if humidity >= 60:
            # 다습 상태 (입김 감지): 빨간색 경보 및 온보드 LED 점등
            board_led.on()
            pixels.fill((255, 0, 0))   # R:255, G:0, B:0 (적색)
            pixels.write()
            print(">> 상태: 습도 높음 (환기 필요)")
        elif humidity < 40:
            # 건조 상태: 파란색 경보
            board_led.off()
            pixels.fill((0, 100, 255)) # R:0, G:100, B:255 (청색)
            pixels.write()
            print(">> 상태: 실내 건조 (가습 필요)")
        else:
            # 쾌적 상태 (40% ~ 59%): 은은한 초록색 점등
            board_led.off()
            pixels.fill((0, 150, 40))   # R:0, G:150, B:40 (녹색)
            pixels.write()
            print(">> 상태: 실내 환경 쾌적")
            
    except OSError as error:
        # 센서 데이터 수신 타이밍 일시 에러 시 재시도 보호
        print("센서 통신 대기 중...")
        time.sleep(0.5)
